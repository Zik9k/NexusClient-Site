## 🎮 About

**Nexus Client** — клиентский мод для **Minecraft 1.21.4**, созданный на платформе **Fabric**.

Клиент имеет модульную архитектуру и собственные интерфейсы для управления функциями прямо во время игры.

Основная цель Nexus Client — удобный интерфейс, простая структура модулей и комфортное использование клиента.

---

## ✨ Features

### 🧩 Modular System

Функции клиента разделены на отдельные модули.

Модули можно включать и выключать во время игры, а архитектура позволяет постепенно добавлять новые функции и настройки.
