## 🎮 About

**Nexus Client** — клиентский мод для **Minecraft 1.21.4**, созданный на платформе **Fabric**.

Клиент имеет модульную архитектуру и собственные интерфейсы для управления функциями прямо во время игры.

Основная цель Nexus Client — удобный интерфейс, простая структура модулей и комфортное использование клиента.

---

## ✨ Features

### 🧩 Modular System

Функции клиента разделены на отдельные модули.

Модули можно включать и выключать во время игры, а архитектура позволяет постепенно добавлять новые функции и настройки.

### 🎛️ Two GUI Menus

Nexus Client имеет два отдельных меню.

#### 🖥️ Standard Menu

Открывается клавишей:

```text
Right Shift
```

Обычное меню без чит-функций, предназначенное для стандартных настроек и функций клиента.

#### ⚙️ Full Feature Menu

Открывается клавишей:

```text
0
```

Меню с полным функционалом клиента, включая **KillAura**, **ESP** и другие модули.

---

## 📥 Installation

1. Установите **Fabric Loader** для Minecraft 1.21.4.
2. Установите **Fabric API**.
3. Скачайте последнюю версию `NexusClient.jar` из раздела **Releases**.
4. Поместите файл в папку:

```text
.minecraft/mods
```

5. Запустите Minecraft через **Fabric 1.21.4**.
